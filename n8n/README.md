# n8n workflow

`workflow.lead-qualification.json` — 20 nodes. Import this file.

Generated by `scripts/build_workflow.py`. Edit the generator, not the JSON, or
your changes are overwritten the next time anyone runs `make workflow`.

## Import

**Docker:**

```bash
docker compose up -d
make import-workflow
```

**Editor UI:** Workflows → ⋯ → *Import from File*.

**CLI:** `n8n import:workflow --input=n8n/workflow.lead-qualification.json`
— note the CLI writes straight to the database, so n8n must be **restarted**
for an import or an activation change to take effect.

Then open the workflow and toggle it **Active**, or the production webhook
returns 404.

## Environment

| Variable | Purpose |
|---|---|
| `API_BASE_URL` | Where the AI service lives. Defaults to `http://api:8000` |
| `API_KEY` | Sent as `X-API-Key`. Leave empty if auth is disabled |
| `SLACK_WEBHOOK_URL` | Incoming webhook. Empty routes to the API fallback |
| `N8N_BLOCK_ENV_ACCESS_IN_NODE=false` | **Required**, or `$env` is unreadable in expressions |

No credentials are stored in the export.
